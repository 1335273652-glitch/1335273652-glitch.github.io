## 本地预览

直接用浏览器打开 `index.html`，或在此目录运行：

```sh
python3 -m http.server 8000
```

然后访问 http://localhost:8000。

## 更新网站

编辑 `index.html` 并推送到 `main` 分支。GitHub Pages 从仓库根目录自动发布。

网站为纯 HTML/CSS，无需安装依赖。`.nojekyll` 用于直接发布静态页面。
